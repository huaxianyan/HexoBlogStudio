给 Hexo 博客用的 Windows 工作台：起本地预览、写文章、看配图、发布都在一个窗口里，不用再开 git bash。单文件 exe，双击即用。

## 新功能

- **本地预览一键起停**：一个按钮跟着状态走——「启动本地预览」/「停止本地预览」，图标和主次色一起变，服务自己退出也会复原。停止时连进程树一起结束，不留后台 node。
- **文章列表与编辑器**：按标题、标签或文件名筛，按日期倒序；内置编辑器 `Ctrl+S` 保存，也可以交给系统里关联的程序打开。
- **配图工作区**：选中文章自动对上 `source/images/<日期目录>` 的缩略图，双击打开、右键插入正文。切换文章不等图，缩略图在后台加载。
- **发布**：写一句提交说明即可。推送前先与远端对齐，再按三条通道依次尝试（22 端口 → ssh 443 经代理 → HTTPS 经代理），日志里能看到走的是哪条。

## 说明

发布沿用原先手工脚本的三通道顺序，没有另立判据。CI 会往博客仓库的 `main` 推主题同步提交，所以推送前会先快进合并，本地有独立提交时停下来提示手动处理。

完整用法与自检命令见 [README](https://github.com/huaxianyan/HexoBlogStudio/blob/v0.1.0/README.md)。
